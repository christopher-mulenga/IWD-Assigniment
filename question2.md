 Question 3: HTML Attributes

1. Three essential attributes:

The three most essential attributes were `href`, `src`, and `alt`. The `href` attribute makes navigation links work, `src` specifies the location of images, and `alt` provides descriptions for images, especially for users using screen readers.

2. Difference between `class` and `id`:

The `id` attribute identifies one specific element on the webpage, such as a section used for navigation. A `class` can be used to identify multiple elements that belong to the same group. In my website, `id` was mainly used to link directly to different sections.

3. Attribute that improved user experience:

The `alt` attribute improved the user experience the most because it provides alternative text for images. This is particularly useful for visually impaired users who may access the website using a screen reader.
